# Contribuir a Marco PDF

Gracias por ayudar a mejorar el proyecto. Antes de proponer un cambio, revisa el [manual](docs/MANUAL.md) y las [instrucciones de desarrollo](docs/DESARROLLO.md).

## Informar de un problema

Incluye la versión, plataforma, pasos para reproducirlo, resultado esperado y resultado real. Si afecta a un PDF, prepara una muestra ficticia pequeña que reproduzca el fallo. No publiques documentos personales ni contraseñas.

## Proponer cambios

1. Describe qué problema resuelve el cambio.
2. Mantén el alcance centrado en ese problema y los textos de interfaz en español.
3. Ejecuta las pruebas relacionadas con el motor o la plataforma modificada.
4. Actualiza el manual cuando cambie el comportamiento y las capturas cuando cambie la interfaz.
5. Abre una propuesta de cambios explicando el resultado y la validación.

Las contribuciones se distribuyen bajo la [licencia AGPL-3.0 del proyecto](LICENSE). No incluyas claves de firma, tokens, documentos privados, entornos de dependencias ni binarios de compilación en Git.
