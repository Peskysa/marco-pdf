# Marco PDF 1.1.0

Primera publicación multiplataforma, del **17 de octubre de 2026**.

[Descargas](https://github.com/Peskysa/marco-pdf/releases/tag/v1.1.0) · [Manual](../MANUAL.md) · [Instalación](../INSTALACION.md)

## Incluye

- Lector con navegación, zoom, búsqueda y texto copiable.
- OCR español/inglés de páginas sin texto previo.
- Selección por rangos y división por páginas o tamaño máximo real en MB.
- Windows: instalador EXE, ZIP portable y EXE portable de archivo único, x64.
- Linux: DEB y TAR.GZ portable, x64; entorno compatible con Ubuntu 22.04/glibc 2.35.
- Web: aplicación privada alojada y ZIP para servir por HTTP/HTTPS.
- Android: APK firmado con clave propia, para instalación directa.

## Comprobaciones realizadas

Las compilaciones de Windows, Linux y Android terminaron correctamente. Se ejecutaron cinco pruebas del motor Python, tres del motor web y un recorrido de navegador con apertura, lectura, búsqueda, división, descargas, límite de bytes, OCR real y pantalla pequeña. La ventana de escritorio se abrió en Windows y, con entorno gráfico virtual, en Linux.

## Límites conocidos

No se ha probado el APK en un móvil físico. El OCR omite páginas con texto previo, puede cometer errores y usa texto latino en web. No se conservan firmas digitales ni marcadores. La web no incorpora PWA. Los PDF con contraseña se abren en escritorio.
