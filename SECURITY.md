# Seguridad

La versión mantenida inicialmente es **1.1.x**. Este proyecto no ofrece un plazo de respuesta ni una auditoría de seguridad certificada.

Para comunicar una vulnerabilidad, utiliza **Security → Advisories → Report a vulnerability** en GitHub si esa opción está disponible para tu cuenta y repositorio. Si no lo está, comunícala al propietario por un canal privado ya acordado; no abras una incidencia con un PDF dañino o datos sensibles.

Incluye plataforma, versión y una reproducción mínima sin documentos personales. Las incidencias de uso normales pueden abrirse mediante [las plantillas del repositorio](https://github.com/Peskysa/marco-pdf/issues/new/choose).

Las claves Android y credenciales de publicación se guardan fuera del código. Los PDF y sus derivados se procesan localmente; consulta [privacidad](docs/PRIVACIDAD.md) para las particularidades del navegador y de la caché de Android.
